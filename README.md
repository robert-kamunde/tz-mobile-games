# tz-mobile-games

Two mobile games for the Tanzanian market, sharing one core: **Pool** (in development) and **Daladala Rush** (after Pool).

Web stack (TypeScript, Phaser 4), packaged for Android. Kiswahili first, works offline, built for low-end phones.

- Start here: `docs/PROJECT_STATUS.md`
- Setup and commands: `docs/DEVELOPMENT.md`
- Design: `docs/GAME_DESIGN.md`, architecture: `docs/ARCHITECTURE.md`, testing: `docs/TESTING.md`

```
npm install
npm run check
```
